## Sobre

Estudante de Engenharia de Software na **Universidade Federal do Amazonas**, trabalhando na fronteira entre software, eletrônica, dados e inteligência artificial.

- **Construo** protótipos de sistemas embarcados, aplicações web/mobile e pipelines de análise de dados.
- **Aplico** IoT em monitoramento, automação e apoio à tomada de decisão.
- **Busco** soluções funcionais e bem estruturadas para problemas reais — do microcontrolador à interface.
